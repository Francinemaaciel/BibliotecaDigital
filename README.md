# 📚 Biblioteca Digital

Este é um projeto de uma **Biblioteca Digital** desenvolvido com **Windows Forms (.NET)** e banco de dados **SQLite**. O sistema permite o gerenciamento de livros e leitores de forma simples e prática, possibilitando cadastrar, editar, excluir e consultar registros.

## 🚀 Funcionalidades

- Cadastro, edição e exclusão de livros 📖  
- Cadastro, edição e exclusão de leitores 👤  
- Visualização de listas de livros e leitores  
- Busca por livros e leitores pelo nome  
- Interface gráfica com Windows Forms  
- Integração com banco de dados SQLite

## 🛠️ Tecnologias Utilizadas

- C# com Windows Forms (.NET Framework)
- SQLite (banco de dados local)
- Visual Studio
